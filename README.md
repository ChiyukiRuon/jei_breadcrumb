# JEI 面包屑

简体中文 | [English](README_EN.md)

这是一个 [JEI](https://github.com/mezz/JustEnoughItems) 的附属模组，它在 JEI 配方页面的顶部添加了一条面包屑导航栏，让你能看清自己是怎么一层层点进来的，并且随时退回去。

---

## 使用方式

在 JEI 配方页面中点击任意物品，这个物品就会成为面包屑中的一个步骤。

- 在**配方页面内**点击物品会延续当前的路径
- 在**侧边的物品列表**以及**书签**中点击物品会重新开始计算路径

> [!NOTE]
> 这是一个客户端模组，仅在客户端安装即可，服务端安装无效。

### 键盘绑定

面包屑的按钮都可以绑定按键，默认**未绑定**，请在 `选项 → 按键控制 → 按键绑定 → JEI 面包屑` 中自行设置。

按住返回或前进键可以连续触发。

---

## 配方与用途

每个步骤都会用颜色边框标出这次查找的方向：

- **绿色**：查看「如何制作这个物品」，即该物品是配方的产物
- **橙色**：查看「这个物品有什么用途」，即该物品是配方的原料

---

## 配置文件

`config/jei_breadcrumb-client.toml`

| 配置项        | 类型      | 默认值      | 说明                                       |
|---------------|-----------|-------------|--------------------------------------------|
| `enabled`     | `boolean` | `true`      | 是否显示面包屑导航栏                       |
| `recipeColor` | `string`  | `"#4CAF50"` | 「配方」标记的颜色，用于图标边框与提示文本 |
| `usesColor`   | `string`  | `"#E08A2E"` | 「用途」标记的颜色，用于图标边框与提示文本 |

> [!NOTE]
> 颜色格式为 `#RRGGBB`，填写错误时会被重置为默认值。

## 命令

### `/jeib debug`

控制**本次游戏运行**是否输出调试日志。

| 命令                  | 说明               |
|-----------------------|--------------------|
| `/jeib debug`         | 查看当前是否已开启 |
| `/jeib debug enable`  | 开启调试日志       |
| `/jeib debug disable` | 关闭调试日志       |

> [!NOTE]
> 这是客户端命令，在服务器上同样可用。开关只对本次运行有效，重启游戏后会自动恢复为关闭。
